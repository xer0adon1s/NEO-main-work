NEO — Linux verification run (home box)
========================================
Updated: 2026-09-01 (Phases 73–74)
Hi! Run ONE command, then email ONE log file back. Takes about 15–30 minutes.

WHAT THIS CHECKS
----------------
Automated tests only — no Hack The Box, no attacks, no API keys required.
Covers everything through Phase 74 (P0 feedback/disclosure + P1 conductor/report/library).

WHAT YOU NEED
-------------
• The NEO folder on Linux (must contain neo.sh)
• Bash (normal on Linux)
• Optional: git (if you pulled from GitHub)

WHERE IS THE NEO FOLDER?
------------------------
Examples:
  ~/NEO-main-work
  ~/Desktop/NEO-main-work
  ~/Neo

The folder must contain neo.sh and a tools/ subfolder.

STEP 0 — Get latest code (if using git)
---------------------------------------
  cd ~/NEO-main-work
  git pull

If you do not use git, make sure the operator sent you the latest zip/copy.

STEP 1 — Run the verification script (ONE command)
--------------------------------------------------
Open Terminal, then paste (change path if needed):

  cd ~/NEO-main-work && bash tools/linux-phase1-verify.sh

If "Permission denied":
  chmod +x tools/linux-phase1-verify.sh
  cd ~/NEO-main-work && bash tools/linux-phase1-verify.sh

STEP 2 — Email the log file back
---------------------------------
When finished, the script prints something like:

  artifacts/linux-phase1-verify-20260901-123456.log

That file is inside the NEO folder under artifacts/.

Attach that .log file to an email and send it to the operator.

NOTES
-----
• Red [FAIL] lines are OK — send the log either way.
• Do not enter passwords unless Linux asks for your login.
• This does NOT connect to Hack The Box or run exploits.
• tmux integration tests need tmux installed (usually already there).
• Some integrity-gate warnings about ListenAssist/FindPrivs stubs may be expected.

TROUBLESHOOTING
---------------
"neo.sh not found"
  → cd into the folder that contains neo.sh first.

"bash: command not found"
  → Try: /bin/bash tools/linux-phase1-verify.sh

"tmux: command not found"
  → Install: sudo apt install tmux   (Debian/Ubuntu)

Script missing after email
  → Save linux-phase1-verify.sh into NEO-main-work/tools/ then run Step 1.

QUESTIONS?
  → Text the operator with a photo of the terminal screen.
